# openv v2 Specifications

This directory contains aspirational specifications for "v2" of the openv operating system.

**Warning:** These documents do not reflect the current implementation of openv. They describe a more advanced microkernel architecture (inspired by Fuchsia and MINIX 3) that is the intended future direction for the project.

For documentation on the current v1 implementation, see the [Architecture Index](../../architecture/README.md) (or the split files in `docs/architecture/`).
